Music Deck already reads the title and artist of whatever Spotify is playing on this PC — that needs no login at all. Connecting your account adds the things Windows cannot tell us: the queue, the album art at full size, and control of Spotify wherever it is playing — your phone, the web player, a speaker.

Spotify has no shared key for apps like this one, so you make your own, which takes about two minutes. It stays on this PC and is tied to your account, not ours.

  1. Open the dashboard. Go to developer.spotify.com/dashboard and log in with your normal Spotify account. Press Create app.
  2. Fill the form. App name and description can be anything — "Music Deck" is fine; nobody else sees them. Leave the website blank.
  3. Add the redirect URI. In Redirect URIs paste this exactly, then press Add: http://127.0.0.1:8713/spotify/callback This is the address on your own PC that Spotify sends you back to after you approve. One wrong character and the approval page will refuse.
  4. Tick Web API. Under Which API/SDKs are you planning to use? tick Web API. Agree to the terms and press Save.
  5. Copy the Client ID. On the app's page open Settings. Copy the Client ID — the long string of letters and numbers. You do not need the client secret; Music Deck uses the flow that does not take one, so there is no secret to leak.
  6. Paste it below and press Connect. A window opens asking you to approve. Say yes and it closes itself.

It said no — what went wrong?
INVALID_CLIENT: Invalid redirect URI
The redirect URI in the dashboard does not match. It must be http://127.0.0.1:8713/spotify/callback — 127.0.0.1, not localhost; http, not https; no trailing slash. Press Add after pasting it, then Save at the bottom of the page.
INVALID_CLIENT: Invalid client id
The Client ID is wrong or has a stray space. Copy it again from the app's Settings page — it is the ID, not the secret.
The approval window never appeared
Use the link that shows up under the Connect button and approve in your normal browser instead.
Connected, but it says nothing is playing
Spotify only reports a device that is actually playing. Start a track, then press Refresh. If you have several devices, pick the right one in the dropdown at the top of this panel.
Buttons do nothing / "Player command failed"
Controlling playback through the API needs Spotify Premium. Reading the queue and what is playing works on a free account; skip, pause and seek do not.
You changed the port
The redirect URI has to match the port Music Deck is running on. If you started it on a different port, add that address in the dashboard too.
Sending this to a friend

A Spotify app starts in development mode, which only lets accounts you have listed use it — up to 25, added by email under Settings → User Management. So either add your friends there, or have each of them make their own app and paste their own Client ID. Everything else in Music Deck works for them with no setup at all.

None of this sends your listening anywhere. The token lives in cache/spotify_token.json next to the app and talks only to Spotify.

Up next

Play now advances to that track, dropping the ones above it — the same thing Spotify's own app does when you click an item in its queue. Spotify's API has no way to reorder or remove queued items, so a true drag-to-reorder is not possible; everything below the track you pick is kept.
